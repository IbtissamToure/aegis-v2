How Aegis decides

  1. Injection screen — instructions hidden in prompts or attached content
  2. Detection — validators, bilingual lexicons and context (EN/AR)
  3. Purpose — which disclosure contract applies to this task
  4. Policy — deterministic YAML rules: ALLOW · WARN · GENERALIZE · BLOCK
  5. Identifiability budget — how many people still match, across prompts
  6. Generalization — least revealing form the task still needs
